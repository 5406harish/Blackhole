# Packaging Black Hole

The extension is already loadable as an unpacked Manifest V3 extension. For local distribution, ZIP the **contents of the `BlackHole` folder** so `manifest.json` is at the ZIP root.

For Chrome Web Store submission, upload the ZIP through the Chrome Web Store Developer Dashboard and complete the listing, privacy, screenshots, icons, and developer-account requirements.

Do not put another `BlackHole` folder above `manifest.json` inside the upload ZIP.
